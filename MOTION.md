# Colour and motion direction

## Palette

Light: warm ivory `#F4F1EA`, charcoal `#252C27`, secondary text `#68716A`, moss accent `#52664D`, divider `#DCDDD4`.

Dark: forest `#151C18`, ivory text `#ECEFE6`, secondary text `#A2ADA2`, pale moss accent `#B7C9A5`, divider `#344138`. App artwork retains its original colours.

## Motion

Applied [LottieFiles motion-design skill](https://github.com/LottieFiles/motion-design-skill), version 1.0.0. Its guidance is implementation-agnostic; this static site uses CSS rather than a Lottie player.

Intent: quiet, considered, responsive. Editorial personality, no bounce or overshoot. Signature easing `(0.4, 0, 0.2, 1)`; durations 90 / 220 / 480 ms. One 6 px page entrance. Hover feedback has a primary arrow move, a secondary 1 px icon lift, and a soft ambient row tint. Both rows share exactly the same treatment. Press feedback compresses only the icon to 98%. No continuous loops or scroll effects. Reduced-motion preference removes spatial motion and transitions.
